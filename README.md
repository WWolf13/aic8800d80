# AIC8800D80 (Wi-Fi 6 / Bluetooth) для ALT Workstation K11

Этот репозиторий является форком оригинального проекта [shenmintao/aic8800d80](https://github.com/shenmintao/aic8800d80). 
Драйвер адаптирован для сборки и стабильной работы в операционной системе **ALT Workstation K11**.

## Что было изменено

* **Адаптация под ALT Linux:** Скрипт `install.sh` доработан для работы с пакетным менеджером ALT (`apt-get`) и именами пакетов. Добавлен автоматический поиск актуального ядра (flavor: `std-def`, `un-def`, `rt` и др.) для установки правильных заголовков `kernel-headers-modules-*`.
* **Чистые логи:** Удалено большое количество отладочной информации (debug printk / debug logging), которая спамила в системный журнал (`dmesg` / `journalctl`).
* **Чистота репозитория:** Добавлен файл `.gitignore`, чтобы артефакты сборки (`.ko`, `.o`, `.cmd` и т.д.) не попадали в Git.
* **Оставлена поддержка Bluetooth:** Сохранена работа стандартного `btusb` и специализированного модуля-костыля `aic_zlp_quirk` для устройств `368b:8d81`.

## Требования

* **ОС:** ALT Workstation K11 (также должен работать на других дистрибутивах семейства ALT).
* **Ядро:** Установленные заголовки ядра (`kernel-headers-modules-<flavor>`).
* **Права:** Доступ с правами `root` (через `sudo`).
* **Secure Boot:** Если в BIOS/UEFI включен Secure Boot, сторонние модули ядра не загрузятся без цифровой подписи. Рекомендуется отключить Secure Boot.

## Установка

Скрипт установки автоматически определит пакетный менеджер, установит необходимые зависимости (включая DKMS и заголовки ядра для ALT), скопирует прошивки и соберет модуль. Благодаря DKMS, драйвер будет автоматически пересобираться при обновлении ядра.

1. Клонируйте репозиторий и перейдите в папку:
    ```bash
    git clone https://github.com/WWolf13/aic8800d80.git
    cd aic8800d80
    ```

2. Сделайте скрипт исполняемым и запустите установку:
    ```bash
    chmod +x install.sh
    sudo ./install.sh
    ``` 
    
3. После завершения установки перезагрузите компьютер или подключите Wi-Fi адаптер.

## Ручная сборка (альтернатива)

Если вы не хотите использовать DKMS или скрипт установки, можно собрать модули вручную:
```bash
cd drivers/aic8800
make
sudo make install
sudo depmod -a
sudo modprobe aic8800_fdrv
```
    
(Обратите внимание: при ручной сборке прошивки из папки `fw` нужно будет скопировать в `/lib/firmware/` вручную).

## Проверка работы

После установки вы можете проверить состояние драйвера следующими командами:

* Статус DKMS: `dkms status`
* Загруженные модули: `lsmod | grep -E 'aic|btusb'`
* Логи драйвера: `sudo dmesg | grep aic8800`
* Проверка Wi-Fi интерфейсов: `ip link show` или `iwconfig`
* Проверка Bluetooth (для комбо-адаптеров): `bluetoothctl list`

## Удаление

Чтобы удалить драйвер из системы:
```bash
sudo dkms remove aic8800/1.0.0 --all
sudo rm -rf /lib/firmware/aic8800*
```
